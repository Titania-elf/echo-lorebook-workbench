# 回声书台 · Echo Workbench

适配本地 SillyTavern 1.18.0 的前端扩展：**全部世界书编辑工作台＋生成前世界书调度器**。

- 主入口：聊天输入区的 **魔法棒 → 回声书台**。
- 备用入口：扩展设置中的 **回声书台 → 打开世界书工作台**。
- 手机优先，圆体标题与原创 SVG 回声徽记；紫绿渐变围绕 `#8360C3 → #2EBF91`，支持日间、夜间和跟随酒馆。
- **工作台手动保存会直接修改原世界书，影响所有使用它的聊天。调度器本身只处理扫描副本，不改写原书。**
- 调度默认关闭，保留原有配置；不切换正文模型连接，不额外保存 API 密钥，不需要构建或安装 npm 依赖。

### 旧配置兼容

`lorebook-director` 仍作为调度配置、聊天规则、工作集、UI 容器的兼容标识；`lorebook-director-workbench` 的 UI 偏好及原书 ID 水位，以及场景指纹前缀也保持不变。这些不是遗漏的安装路径，不应全局替换或清空，否则可能丢失既有状态。

初始化会把旧目录的插件禁用记录迁移到实际安装目录；拦截器也识别新旧名称。全局 `lorebookDirectorInterceptor` 和原生接入契约继续兼容。目录改名不要求修改任何原世界书、聊天文件或 API 密钥。

## 世界书工作台

刷新酒馆页面后从魔法棒打开，不要继续使用 `design/preview.html` 进行实际编辑：那个页面仍是独立示例草图，不读取真实资料。

### 书库与默认目标

- 书库包含**全部酒馆世界书**，未挂载、未托管的书也能打开和编辑。
- 从聊天打开时优先当前角色卡的主书与辅助绑定书，其后是**当前已启用的全局书**；其他聊天／人设挂载和未挂载的书仍可切换。
- “全局已启用”表示世界书挂载设置，不等于上轮某个条目实际激活。
- 群聊有明确当前角色时参考该角色；没有时从已启用全局书开始，不合并全部群成员调度。
- 页面始终显示当前打开的书。点击 **新增** 直接进入这本书的新条目编辑，不再弹出目标书选择。
- 切换、查看和编辑不会自动挂载世界书，也不会自动把它交给调度器。
- 全库为空时先通过酒馆原生界面创建或导入一本书，再刷新书库；本期不新增整本书创建／改名／删除／导入导出功能。

### 查看、编辑与保存

- 当前书支持标题、主／次关键词和全文搜索，支持状态筛选；每页 50 条，不以显示前 150 条代替完整浏览。
- 编辑支持标题／备注、全文、关键词、原生启用、蓝绿灯／向量状态、次关键词逻辑、全部原生插入位置、顺序、深度／角色、概率、部分递归／预算／匹配覆盖属性。
- 未显示或未编辑的原生属性、扩展字段及其他条目取最新原值，不以表单重建整个条目。未知枚举保留原值，nullable 字段不统一压成 0 或 false。
- 点击 **保存到原书** 才提交。新增、复制的草稿尚未保存时不进入调度；允许原生空条目，空正文不会进入本地调度目录。
- 复制保留原生属性，分配新 UID，不继承本聊天固定／排除。
- 删除单独确认，影响所有使用原书的聊天；不是“本聊天排除”。异常 ID 的条目只提供原始数据查看，不覆盖写入。
- 返回、换书或关闭时处理未保存草稿；调度状态刷新不重建编辑表单。未保存草稿仅在当前页面内存中，刷新、退出浏览器或系统结束页面可能丢失。

### 保存边界

- 新写入层检查 HTTP 与后端 `{ ok:true }`，确认后才更新原生缓存和当前同名原生编辑器，不把 `saveWorldInfo()` 的正常 void 返回当作成功。
- 提交前检查真实目录，避免把已删除／改名的书加载成 dummy 空书后重新创建；按当前书名锁定提交目标。
- 同一工作台内的同书写入串行，读取最新原书并检查修改字段冲突。失败／冲突保留草稿，不自动覆盖或自动重试。
- 网络中断、服务端错误或无法解析保存响应时，结果可能不确定：保留提交身份、暂时锁定字段，重试先读取原书，避免盲目重复新增。直接离开不能撤销已经发出的请求。
- 已发出的写入即使聊天切换也只完成锁定的原书；旧编辑页不能把固定／排除写入新聊天。
- **宿主没有版本号或 CAS，不能保证多标签页原子事务。**原生编辑器有共享防抖和旧快照，其他工具／窗口仍可能整书覆盖；避免同时编辑同一本书。
- 新增／删除会在原书 `extensions.lorebook-director-workbench.uidWatermark` 保存本插件的 ID 水位；标准角色书镜像可同步该记录。水位随条目变化同一 JSON 写入，避免仅靠 UI 防抖导致删除 ID 被本工作台重复使用。
- 不保证其他工具、重新导入或整本书替换遵守该身份记录；手动规则不是权限控制。达到原生 ID 安全分配上限时明确失败，不静默复用历史空洞。
- 含 `originalData.entries` 的角色书对已知字段做 id／uid 兼容同步，以及 disable／enabled 取反；不承诺任意外部格式完整往返或自动修复损坏元数据。

### 主题与素材

- **日间／夜间**：独立配色，原色渐变用于品牌与强调，按钮使用对应深浅变体，正文使用中性表面。
- **跟随酒馆**：继承实际 `--SmartThemeBodyColor`、`--SmartThemeBlurTintColor`、`--SmartThemeBorderColor` 等变量，不用手机系统日夜模式替代。
- 界面偏好独立保存于扩展设置，不经调度设置更新；切主题不会取消辅助模型请求。
- 本地完整中文圆体字体与 SVG，不依赖外部字体 CDN。字体保留 SIL OFL 1.1，图标保留 Lucide／Feather 许可，见 `assets/`。

## 开始使用调度器

1. 打开角色聊天，按酒馆原生方式挂载世界书（角色、全局、聊天或人设书）。
2. 打开回声书台的 **调度器 → 调度设置**，选择托管书。勾选未挂载的书不会加载到本聊天。
3. 选择辅助模型连接：
   - **当前聊天补全连接**：复用当前模型与路由；当前主 API 必须是聊天补全。
   - **已保存连接配置**：使用连接管理器中的独立配置，不切换正文连接；配置失效时明确报错，不偷偷改用其他连接。
4. 刷新本地目录，默认为标题与前 240 字原文摘录，没有模型费用。
5. 可单独使用 **AI 概括目录（调用 API）**；只处理新增／改变条目，保存原文不会自动调用它。
6. 可使用 **试选（调用 API）**，查看理由并设置“本聊天固定／排除”。
7. 开启 **启用生成前调度** 后，正常聊天触发调度。

默认值保留：8 条、1800 tokens、最近 8 条消息、超时 60 秒。必须一直生效的核心规则宜放在未托管书中。

### 会发送什么

- 默认每次正文生成前增加一次辅助模型请求；只有固定／排除或没有可用条目时可以不调用模型。
- 选书请求发送最近对话、经当前消息前缀校验的旧场景／工作集和条目目录，不主动发送整个正文预设或完整聊天。
- AI 概括发送对应条目原文；每批最多 6 条、合计约 12000 字符。单条超过 10000 字符时不偷偷截断总结，而保留本地摘录并提示拆分。
- 原文通过原生世界书扫描进入正文；辅助模型的选择理由不注入正文。
- 浏览、编辑与保存只走酒馆后端，不调用辅助模型。模型请求仍使用酒馆已有后端／连接配置；不要选择不愿发送这些资料的 API 服务。

## 调度规则（保留）

### 托管范围与手动规则

- 托管书内蓝灯与绿灯都由调度器决定是否入选，扫描副本的门控不反写原文件。原生禁用不能被固定复活；未托管书走原生规则。
- 托管书选择全局保存，只有本聊天原生挂载的书参与；共享预算、递归、互斥组仍可能相互影响。
- 固定／排除保存于本聊天元数据，直到手动解除，不随场景自动退出；已禁用或不再挂载的旧规则仍可解除。
- 固定优先，但受本插件数量／Token 上限，超限明确显示，原文不截断。
- 清空场景记忆只清快照，不清手动规则。

### 工作集与实际激活

- 模型每轮返回完整选择：`scene` 可作为下轮参考，`turn` 不自动携带；保留不是永久激活，每轮仍要确认。
- 最近 16 个有效快照保存到聊天元数据，以完整消息前缀指纹区分编辑、重生成、滑动分支，不只凭聊天长度复用。
- 只将原生实际激活的场景资料写回工作集。
- 保存原书会失效旧调度请求／闸门，下一次重新选择；已经发送给正文模型的提示词不追溯改变。
- 调度页分别显示选择与实际激活，并可打开对应原条目；更改原书后的旧报告标为过期。

### 试选与预算

- 试选只读已发送聊天，不含输入框草稿，不注入正文、不更新工作集；不执行主流程全部正则／文件转换，不是最终提示词预览。
- Tokenizer 对宏替换后原文计数用于预筛，不是最终提示词精确计数；随机宏、装饰符及其他插件可能改变实际值。
- 原生位置、深度、角色、顺序、预算、概率、互斥组、角色与生成类型过滤仍适用。**选中不等于最终激活**；原生 ignoreBudget 不能越过本插件预筛。

### 失败与限制

- API 错误、超时或非法 JSON 时本轮回退原生触发，不阻断正文。回退后本插件的手动排除也不限制原生扫描，不能用于严格剧透锁／权限控制。
- 未解锁资料宜继续靠原生禁用／挂载等硬条件，而非只靠模型承诺。
- 普通回复、重生成、滑动、续写会调度；安静生成、代写用户、原生 dry-run 提示预览不调用辅助调度模型。
- 托管模式改变扫描副本激活字段及哈希，不保证原生 sticky／cooldown 连续；以本插件场景工作集管理持续资料。
- `WORLDINFO_ENTRIES_LOADED` 没有请求 ID，普通串行是主要场景；多个插件并发构建提示词不能保证严格隔离。
- 目录超过 60000 字符明确失败／回退，不无声丢尾部。本版没有向量检索；本地摘录或 AI 概括也不保证长设定主题完整。

## 文件组织

- `index.js`：宿主事件、拦截器、魔法棒及初始化。
- `core.js` / `director.js` / `transport.js`：现有调度纯逻辑、生命周期及连接；增加视图订阅与原书变更联动。
- `native-adapter.js`：原始书库、原书 HTTP 读写、缓存、字段及格式同步。
- `entry-store.js` / `workbench-state.js`：独立草稿、修改字段合并、结果不确定处理、UI 偏好与身份水位。
- `workbench.js` / `workbench.html`：工作台生命周期、书目／条目浏览、筛选、底部面板。
- `entry-editor.js` / `scheduler-ui.js` / `workbench-utils.js`：编辑表单、调度展示与安全 DOM／图标工具。
- `ui.js` / `settings.html`：兼容原扩展设置面板，保留 `ld-*` 与原功能，提供备用入口。
- `style.css`：只负责 `@import`；`styles/` 按 tokens、themes、base、workbench、books、entries、editor、scheduler、overlays、settings 解耦。
- `assets/`：原创徽记、完整本地圆体及授权。
- `design/`：独立示例设计草图，与真实世界书操作隔离。
- `tests/`：已有模拟逻辑与隔离浏览器夹具。本次只维护新静态资源白名单与 MIME，不执行测试。
