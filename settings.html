回声书台

主入口在魔法棒菜单。工作台可编辑全部世界书；保存直接修改原书，不自动挂载。日间、夜间及跟随酒馆主题在工作台中切换。

目录选书 → 场景工作集 → 原文交给酒馆原生扫描。调度本身不改写原书，默认关闭；手动编辑保存会修改原书。

启用前请了解：托管范围与失败回退

仅托管下方勾选、且已通过酒馆原生方式挂载到当前聊天的世界书。托管书内蓝灯和绿灯都交给调度器；必须常驻的条目请手动固定，或放在未托管的书里。

API 超时、无效 JSON 等错误会让本轮回退原生触发，此时手动排除也不生效。此最小版不适合作为严格的剧透锁或权限控制。

每次生成通常增加一次辅助模型调用，会发送最近对话、旧场景和目录。AI 概括目录按钮还会发送条目原文。不额外保存 API 密钥。

普通回复、重生成、滑动重写、续写会调度；安静生成、代写用户和酒馆提示词预览仍走原生规则。其他插件若并发构建提示词，可能使本轮回退原生。

原生位置、预算、概率、互斥组、角色过滤等仍可阻止选中条目激活。托管模式不保证原生黏性/冷却计时连续，请用这里的场景工作集管理保留。
